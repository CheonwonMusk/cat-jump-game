# 🐾 냥이의 파스텔 2단 점프 (Cat Jump Game)

귀엽고 사랑스러운 파스텔 톤의 모바일 최적화 고양이 점프 액션 게임입니다.  
HTML5 Canvas와 Web Audio API로 구현되어 별도 설치나 외부 라이브러리 없이 단일 파일로 동작합니다.

## 🎮 게임 특징

- **스마트폰 비율 (9:16)**: 모바일 환경에 최적화된 반응형 뷰포트
- **✨ 2단 점프 & 공중제비**: 공중에서 한 번 더 점프하여 360도 공중제비와 무지개 별빛 파티클 발동
- **🎨 10점 단위 실시간 파스텔 테마 변경**:
  - 0~9점: 🌸 봄빛 피치
  - 10~19점: 🌿 민트 브리즈
  - 20~29점: 🔮 몽환 라벤더
  - 30~39점: 🌅 노을빛 캔디
  - 40~49점: 🌌 별빛 트와일라잇
  - 50점 이상: 🍬 달콤 솜사탕
- **🎶 Web Audio API 효과음**: 점프음, 2단 점프음, 득점음, 10점 축하 멜로디, 게임오버 사운드 내장 (음소거 기능 지원)
- **🏆 최고 기록 저장**: 브라우저 로컬 스토리지(`localStorage`) 자동 저장

---

## 🕹️ 조작 방법

| 액션 | 키보드 | 모바일 / 마우스 |
| :--- | :--- | :--- |
| **점프 / 2단 점프** | `스페이스바` 또는 `↑ 방향키` | 화면 어디든 탭(클릭) |
| **게임 시작 / 재시작** | `스페이스바` 또는 버튼 클릭 | 화면 터치 또는 시작 버튼 터치 |

---

## 🚀 실행 방법

1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge, Safari 등)에서 바로 실행합니다.
3. 모바일 화면 느낌으로 플레이하려면 브라우저 개발자 도구(`F12`)에서 모바일 디바이스 툴바(`Ctrl+Shift+M`)를 켜주세요.
